# Employee Attrition Prediction

## Project Overview

This project predicts employee attrition using machine learning techniques on the IBM HR Analytics dataset.

## Dataset

IBM HR Analytics Employee Attrition Dataset

Rows: 1470

Columns: 35

## Objectives

* Analyze employee attrition patterns
* Identify factors influencing employee exits
* Build predictive machine learning models
* Provide HR-focused recommendations

## Models Used

* Logistic Regression
* Random Forest Classifier
* Gradient Boosting Classifier

## Best Model

Logistic Regression

ROC-AUC Score: 0.7986

## Key Findings

* Overtime is strongly associated with attrition.
* Laboratory Technicians and Sales Representatives have higher turnover rates.
* Poor work-life balance increases attrition risk.
* Lack of promotion opportunities contributes to employee exits.
